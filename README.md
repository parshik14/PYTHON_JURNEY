**Project Overview**
- **Name:**: PYTHON_JOURNEY — a small collection of daily Python practice notebooks and exercises.
- **Purpose:**: Track learning progress with one directory per day containing example code and notes.

**Repository Structure**
- **Root files:**: `README.md`
- **Day folders:**:
	- `Day-01/` — contains `day1.ipynb` (first-day exercises and examples).
	- `Day-02/` — contains `day2.ipynb` (second-day exercises and examples).

**Prerequisites**
- **Python:**: Python 3.8+ installed and available on `PATH`.
- **Tools:**: `pip` and `jupyter` (or `jupyterlab`) for running notebooks.

**Setup**
- Create and activate a virtual environment (Windows `cmd.exe`):

```
python -m venv .venv
.venv\Scripts\activate
```

- Install Jupyter if you don't have it:

```
pip install jupyter
```

**Running Notebooks**
- Start the Jupyter server and open the notebook in your browser:

```
jupyter notebook
```

- Then open: `Day-01/day1.ipynb` and run the cells interactively.

**How to Add New Days**
- Create a new folder named `Day-XX` (e.g., `Day-02`) and add a notebook (e.g., `day2.ipynb`).
- Commit new notebooks with a brief description of what you covered that day.

- This repository currently contains a single notebook in `Day-01/`. Expand by adding exercises, solutions, and notes per day.
